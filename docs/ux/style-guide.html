用法

Archivo Black 只用在數字、標題、角色名、資源值 — 它沒有中文字，中文自動落到 Noto Sans TC 900。Space Grotesk 400/500/600/700 承擔所有句子與 UI 文字（英文句子的 x-height 大、易讀）。IBM Plex Mono 只用於標籤、鍵盤鍵帽、計時、數值 — 不用來排句子。

Meter｜三條 0–10 的世界狀態。解剖：label（中英）＋ 數值 ＋ delta ＋ track ＋ fill。狀態：idle／changing（寬度 900ms 過渡、delta 淡入 300ms 後停留 2s）／clamped（到 0 或 10 時 fill 末端加 2px 白邊）。顏色不是唯一訊號：delta 一定帶 ▲▼ 與數字，label 註明「越低越好」。高度 10px＋border-radius 5px，整條 row 可點（44px）展開「這條表示什麼」。
