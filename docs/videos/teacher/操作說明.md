# 老師操作說明

老師後台的三件事：建立課程與匯入名單、看學習紀錄與聽錄音、修改教材。後台網址：`/pages/teacher_dashboard.html`（需要老師或管理員帳號）。

## 課程與名單

影片：`01-課程與名單.webm`（0 分 32 秒，1471 KB）

| 步驟 | 影片時間 | 說明 |
|---|---|---|
| 1 | 0:03 | 老師後台左邊是選單。先到「課程與名單」建立課程。 |
| 2 | 0:06 | 按「＋ 新增課程」，填學期、課號、課程名稱。 |
| 3 | 0:12 | 勾選這門課要開放的主題和難度：勾了就自動儲存。學生在卡牌遊戲只會看到這些。有 🔒 的主題要先到教材管理開放。 |
| 4 | 0:15 | 匯入名單：從試算表複製貼上。欄位是系級、學號、姓名、email；每位學生都要有系級。 |
| 5 | 0:18 | 先按「預覽」：系統會告訴你每一列會怎麼處理，有問題的列會標出來，這時候還不會寫入。 |
| 6 | 0:22 | 確認沒問題再按「確認匯入」。同一份名單重複匯入也不會產生重複帳號。 |
| 7 | 0:24 | 帳號單只顯示這一次：每位學生的帳號和初始密碼。請現在下載，發給學生。 |
| 8 | 0:27 | 下面的學生名單可以重設密碼、標記退選。學生第一次登入時要先換成自己的密碼。 |
| 9 | 0:29 | 最下面是籌碼：每位學生有幾個、哪些局的籌碼在等你確認，也可以手動加減並寫理由。 |

## 學習紀錄與語音

影片：`02-學習紀錄與語音.webm`（0 分 45 秒，1569 KB）

| 步驟 | 影片時間 | 說明 |
|---|---|---|
| 1 | 0:03 | 「學習紀錄」可以看每個遊戲、每位學生、每一局的完整資料。 |
| 2 | 0:06 | 先選課程。最上面會列出「先看這幾位」和原因，例如還沒玩、分數偏低、有錄音還沒聽。 |
| 3 | 0:09 | 學生表：每位學生的系級、局數、分數變化、第一次就配對幾句、有沒有送出錄音。還沒玩的也會列出來。 |
| 4 | 0:12 | 最難的句子：全班哪一句最常第一次配錯、最常被放到哪一張。上面有一句白話結論。 |
| 5 | 0:15 | 點一位學生，看他的個人總覽。 |
| 6 | 0:18 | 個人總覽：玩過哪些遊戲、各主題的進步、需要再練的句子、他送出的錄音。 |
| 7 | 0:21 | 最下面是他的每一局。點一局可以看每一張卡：第一次對不對、放了幾次、重聽幾次、放錯到哪一張。 |
| 8 | 0:27 | 回到全班，切到「語音」：學生念完自動送出的錄音都在這裡。 |
| 9 | 0:31 | 按「播放」就能聽，旁邊有學生念的原文、秒數和語速。播放後自動標成「已聽」。 |
| 10 | 0:35 | 把狀態改成「請重錄」並寫一句回饋（改了就會儲存）：學生下次會被要求重念這一張，並看到你的回饋。 |
| 11 | 0:41 | 回到「依遊戲看全班」可以匯出 Excel：含姓名的給自己看，只有研究代碼的可以給研究用。 |

## 教材管理

影片：`03-教材管理.webm`（0 分 49 秒，1698 KB）

| 步驟 | 影片時間 | 說明 |
|---|---|---|
| 1 | 0:03 | 「教材管理」：學生在遊戲裡看到的主題、投影片標題和講稿，都在這裡改。 |
| 2 | 0:06 | 左邊是樹狀清單：遊戲 → 主題 → 難度。可以用上面的搜尋框找主題。 |
| 3 | 0:10 | 右邊上面是主題的狀態：現在學生看到的是第幾版。下面依段落列出每一張投影片。 |
| 4 | 0:14 | 點一張投影片就能改標題和講稿。講稿下面會算字數和大約要念幾秒。 |
| 5 | 0:17 | 改完不用按儲存：自動存成「草稿」，學生還看不到。改到講稿時會提醒你發佈後是新的一版。 |
| 6 | 0:20 | 按「預覽」可以用學生的畫面先玩玩看這份草稿（不會留下紀錄）。確認後按「發佈給學生」。 |
| 7 | 0:25 | 發佈後學生就會看到新內容。每一版都留著，「發佈紀錄」裡可以把舊版取回來。 |
| 8 | 0:30 | 刪除不會跳出確認視窗：直接刪，下方會出現「復原」。例如刪掉一張投影片… |
| 9 | 0:34 | …按「復原」就回來了。少一張時，上面也會用白話告訴你哪裡不對、不讓你發佈。 |
| 10 | 0:37 | 要新增主題：按左下「＋ 新增主題」，可以從空白開始、複製現有主題，或從試算表整批貼上匯入。 |
| 11 | 0:44 | 每個主題都能上鎖、匯出 Excel、刪除（可復原）。3D 遊戲的教材目前還不能在這裡改，清單最下面有說明。 |
