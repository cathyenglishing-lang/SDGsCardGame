# 學生操作說明

從拿到帳號到玩完一局卡牌遊戲、朗讀並送出錄音。整個流程大約 15–20 分鐘（影片把配對的部分加快了）。

## 登入到玩完一局

影片：`01-登入到玩完一局.webm`（1 分 44 秒，3399 KB）

| 步驟 | 影片時間 | 說明 |
|---|---|---|
| 1 | 0:02 | 用老師發給你的帳號（學號@學校信箱）和初始密碼登入。 |
| 2 | 0:07 | 第一次登入要先換成自己的密碼：至少 8 個字，要有英文字母和數字。 |

| 8 | 0:29 | 把句子點到（或拖到）對應的投影片卡上。配錯會晃一下，可以再試；想再聽就再按喇叭。 |

| 13 | 1:32 | 錄音會自動送給老師。可以試聽、重錄；老師之後給的回饋，下次念這一張時會看到。 |
| 14 | 1:36 | 最後一步：這一局拿到的籌碼、個人紀錄、建議哪一天再來。想多練可以做小測或寫一句反思。 |
