## 3. 做完的部分

### 3.1 T4 教材不可空白

- `title_zh`（中文標題）空白現在是**錯誤**：`npm run build` 會停、老師後台不能發佈。主題的中文名稱也一樣。改在 `scripts/validate-content.mjs` 和 `backend/content_library.py` 的 `check_doc`。
- 題庫裡 9-1 的 18 張空白中文標題補上了（6 個標題 × 3 個難度）。**字是公司端的 agent 依英文標題寫的，請老師看一下**：AI 與 SDG 9 的連結／問題：AI 的「幻覺」／科學解釋：為什麼會這樣？／對社會的影響與重要性／AI 素養策略二：查證來源／結論：謹慎使用 AI。中文標題不在資料雜湊裡，所以版本號沒有加。
- 已經有資料的資料庫：啟動時 `_backfill_title_zh` 把「還是空白、而且英文標題和題庫同一張一樣」的中文標題從 `pk-content.js` 補進去。只補空白，不覆蓋老師改過的。
- **和會議紀錄不一樣的地方**：`keywords`（提示）還是只有提醒，不是錯誤。原因：488 張卡裡 468 張是空的（只有 9-1 的 A2、B1 各 10 張有，而且寫的是中文大綱不是英文），改成錯誤會讓建置失敗、9 個主題都不能發佈。使用者 2026-11-11 選了「中文標題改錯誤，提示先只提醒」。老師填完之後，把兩個檔案裡那一行的 `warnings` 換成 `errors` 就好。

### 3.2 T5 測試資料保留但不進分析，以及快速測試

哪些算測試資料：

- `teacher`、`admin` 角色的帳號（固定，不能取消）
- 老師在「課程與名單」學生列勾「不計」的帳號（新欄位 `users.test_account`；`PATCH /teacher/users/{id}/test-account`）
- 3D 遊戲裡的小站（原本就排除）
- 快速測試的局（`metrics.test`）和只玩部分段落的局（`metrics.parts`）

規則：

- 這些局**都還在資料庫**，個人頁照常顯示並標「測試帳號」。
- 不計入：學習紀錄的全班數字、各系級比較、題目難度、混淆表、漏斗、異常偵測、舊的 3D 分析頁（`/learning/analytics`）和它的 Excel。
- 學習紀錄上方會寫「另有 N 局不計入：測試帳號 x 局、快速測試 y 局…」。局列表裡每一局有標記（欄位 `excluded`：`test_account`／`embed`／`test_run`／`partial`）。
- Excel（`/learning/records/export.xlsx`）：`Students` 沒有測試帳號；`Runs` 列出全部並多一欄 `excluded_reason`；`CardAttempts`、`Quiz`、`ReadAloud`、`Reflections` 只有計入的局；`Events` 是全部原始紀錄。
- 測試局不給籌碼（收尾寫「測試局：不給籌碼，也不進班級統計」）。

快速測試：

- 老師、管理員、測試帳號在卡牌遊戲的任務卡上會看到「快速測試」勾選框：勾了只玩第 1 段（2–3 張），配完直接進收尾。學生帳號看不到。
- 網址加 `?quick=1` 也可以（任何帳號），這種局一樣標成測試、不計入。
- 自動操作從開頁面到收尾大約 7 秒。

**要注意**：正式站上線後，老師自己以前玩的局會立刻從全班數字裡消失（因為老師帳號算測試）。這是要的效果，但老師可能會問「數字怎麼變了」。

### 3.3 T2 語音念法表

- 朗讀前先把文字換成「念法」，畫面上的字不變。例：`SDG 4` 念成 `S D G 4`、`SDGs` 念成 `S D Gs`、`e.g.` 念成 `for example`；破折號、分號、冒號變成停頓。
- **念法表全系統共用，老師可以改**：老師後台 › 教材 › 語音念法。可以加列、改、刪（可復原）、恢復內建的表；「試一句」打一句英文就看到會念成什麼，也可以試聽。
- 規則：只換完整的一個字（`ChatGPT` 裡的 `GPT` 不換）；全大寫縮寫加複數 s 一起處理；要照原樣念的（STEM、NASA）不放進表裡。
- 資料：`speech_rules` 資料表（`backend/speech_rules.py`）。`GET /content/speech` 給遊戲（不用登入），`GET/PUT /teacher/speech`、`POST /teacher/speech/reset` 給老師。
- 遊戲端：`frontend/js/speech-say.js` 的 `CardLearnSay(text)`。開頁面時抓最新的表，存在瀏覽器裡；抓不到就用上次的或內建的。接上的地方：卡牌遊戲（含收尾）、Innovation Harbor、舊的 `game_s.html`。
- **同一套規則有兩份**：瀏覽器的 `CardLearnSay()` 和伺服器的 `speech_rules.say()`（雲端語音用）。改規則要兩邊一起改；`scripts/test_classroom.py` 有六個例句檢查伺服器這一份。

### 3.4 雲端語音與多種口音

**狀態：程式做完、用假的廠商測過流程，沒有金鑰，所以還沒用真的雲端語音念過任何一句。** 沒有金鑰時遊戲和以前一樣用裝置自己的聲音（瀏覽器內建的 Web Speech API，優先 Google US English）。

使用者的決定（2026-11-11）：Azure 和 Google 兩家都接；額度用完要能退回本地；口音由老師在後台勾選。使用者提到「像劍橋字典那樣走 https 帶語音回來」：沒有照做，抓別人網站的聲音違反使用條款，而且它只有單字；Azure／Google 的 API 就是正規的同一種做法。

怎麼運作：

- 一句話、一種口音**只產生一次**，存成 mp3 放在伺服器，之後每台裝置播的都是同一個檔。教材共約 488 句、12.3 萬字元，所以一種口音大約用 12.3 萬字元，只算一次；約 50 MB 磁碟。
- 學生只能要「已發佈教材裡的句子」，不能叫它念任意文字（不然任何人都能把額度用光）。老師可以試聽自己打的短句（300 字元內）。
- 送去念的文字先過念法表；改了念法表或講稿，只有受影響的句子會重新產生。
- 廠商順序老師可以改（預設先 Azure 再 Google）。每家有每月字元上限（預設 Azure 45 萬、Google 90 萬，略低於免費額度）。
- **退回裝置聲音的情況**：沒有金鑰、該月上限用完、廠商回錯或逾時（之後 5 分鐘不再問那一家；金鑰錯誤是 30 分鐘）、學生選「這台裝置的聲音」、7 秒內沒拿到音檔。遊戲不會因為雲端語音卡住。
- 已經存好的音檔，就算額度用完或金鑰拿掉也照樣播。

畫面：

- 學生：選難度的牌背面有「朗讀口音」選單；牌桌上喇叭下面有「口音」按鈕，按一下換下一種（最後一個是「這台裝置的聲音」）。選擇記在瀏覽器裡。
- 老師：後台 › 教材 › 語音念法 的最下面「雲端語音與口音」：各家金鑰有沒有設定、這個月用了多少、每月上限、哪家先用；口音表可以勾「開放」、選預設、試聽、「先準備好全部」（事先把整套教材產生好，學生第一次聽不用等）。
- 可選的口音：美、英、澳、印（兩家都有），加拿大、愛爾蘭、紐西蘭、新加坡、南非、菲律賓、香港（只有 Azure）。聲音名稱可以用環境變數 `TTS_VOICES_JSON` 換。

上線步驟：

1. 到 Azure 開一個 Speech 資源（免費 F0 層），拿到金鑰和區域。要 Google 的話到 Google Cloud 開 Text-to-Speech API，建一把限定這個 API 的金鑰。
2. 在 VM 的 `~/cardlearn/.env` 加 `AZURE_SPEECH_KEY`、`AZURE_SPEECH_REGION`（和／或 `GOOGLE_TTS_API_KEY`），重建 app。變數說明在 `.env.example`。**金鑰不要進 repo。**
3. 到後台 › 語音念法，確認顯示「已設定」→ 試聽 → 勾要開放的口音 → 按「先準備好全部」。
4. 音檔放在 `AUDIO_DIR/tts`，在 VM 上就是 `~/cardlearn/data/audio/tts`：這個資料夾有掛出來，重建容器不會不見，也會跟著每週的錄音備份。不用另外設 `TTS_DIR`。

程式：`backend/tts.py`（資料表 `tts_settings`、`tts_usage`、`tts_clips`；`GET /content/tts/options`、`GET /content/tts`、`GET/PUT /teacher/tts`、`POST /teacher/tts/try`、`POST /teacher/tts/prepare`）、`pecha_kucha_builder.html` 的 `PK_TTS`／`pkClip`／`speak`、`teacher-speech.js` 的雲端面板。

### 3.7 主題代號顯示成 9-A、4-B

- 老師的意思：9-1、9-2、9-3 看起來像有先後順序，其實沒有。

## 6. 給接手的 agent 的提醒

- 兩台電腦輪流開發同一個 repo：接手先 `git fetch --all`，看 `origin/main` 有沒有新東西。
- SQL 裡不要寫字面的 `%`（psycopg 會當成參數），這次新增的查詢都沒有；`scripts/test_classroom.py` 有一項專門檢查。
- 念法規則有兩份（§3.3），改一邊要改另一邊。
- `backend/tts.py` 的 `/content/tts` 故意只認已發佈教材的句子。要讓別的遊戲用，要把那個遊戲的句子加進 `material_texts`（`main.py` 接線的地方），不要把限制拿掉。
- 公司電腦的事（跟家裡無關，留作紀錄）：本機測試用的 PostgreSQL 要避開 55432（Docker Desktop 會佔用）；那台電腦另有系統服務 `postgresql-x64-18`，不要用「關掉所有 postgres」這種指令。
